# LeetCode Daily Problems

Solutions to LeetCode and data structures & algorithms practice problems, organized by topic. Mostly Python, with a few Java solutions.

## Structure

```
LeetcodeDailyProblems/
├── sorting/            # Bubble, insertion, merge, quick, selection sort
├── stacks-queues/      # Stack, queue, and linked-list-based implementations, MinStack
├── linked-list/        # Singly linked list, vector implementation
├── arrays-searching/   # Two-sum, peak finding, pair finding, duplicates, common elements
├── math/               # HCF, prime numbers, twin primes
└── misc/               # Triangle class, tree comparison (Same Tree), other one-offs
```

## Topics covered

| Category | Problems |
|---|---|
| Sorting | Bubble, insertion, merge, quick, selection sort, sort-in-range |
| Stacks & Queues | Array/linked-list based stack & queue, MinStack |
| Linked Lists | Singly linked list operations, vector |
| Arrays & Searching | Peak finding, two sum, common elements, pair finding, min difference, duplicate removal |
| Math | HCF, prime checking, prime products, twin primes |
| Trees | Same Tree comparison |

## Running

Python files can be run directly:
```bash
python3 sorting/QuickSort.py
```

Java files need compiling first:
```bash
cd arrays-searching
javac TwoSum.java && java TwoSum
```
